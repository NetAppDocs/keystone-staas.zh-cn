= Keystone STaaS 存储指标和定义
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Keystone STaaS 使用特定术语来衡量和报告您的存储订阅。了解这些术语有助于您解读控制面板数据和订阅报告。

[cols="1,3"]
|===
| 术语 | 定义 


| 容量（GiB, TiB, PiB） | 数据存储容量使用 1024 的幂来衡量：1 GiB = 1024^3^ 字节，1 TiB = 1024^4^ 字节，1 PiB = 1024^5^ 字节。 


| IOPS | IOPS（每秒 I/O 操作数）是应用程序每秒请求的协议操作数。IOPS 显示在 Keystone 仪表板上的运营计数器图表中。 


| 可用性 | 可用性是服务成功响应的 I/O 请求占一个月内发出的 I/O 请求总数的百分比。这是在一个月内的服务分界点处进行衡量的，不包括计划内的服务停机时间，也不包括客户提供的设施、网络或其他服务不可用的情况。 


| 耐用性 | 持久性是指在不损失保真度的情况下可以访问的数据百分比，不包括客户导致的删除或损坏。 


| 延迟 | 延迟是在服务分界点（存储控制器 I/O 端口）测量的为从客户端接收的 I/O 请求提供服务的时间。 
|===
